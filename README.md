# Nacencomm.vn Demo Website (https://webca2demooo.vercel.app/index.html)

A premium, high-conversion demo website for Nacencomm built with Vanilla HTML, CSS, and JS.

## Features
- **14 Products**: Complete data for all Nacencomm solutions.
- **Dynamic Routing**: Uses URL parameters for product details and registration.
- **Multi-step Flow**: Comprehensive online registration process.
- **Modern UI**: Follows the brand design system with navy blue and red accents.

## How to Run
1. Open `index.html` in any modern web browser.
2. For the best experience, use a local server:
   - Python: `python -m http.server 3000`
   - Node: `npx serve .`

## File Structure
- `index.html`: Home page.
- `products.html`: Product catalog.
- `product-detail.html`: Product details template.
- `register.html`: Multi-step registration form.
- `style/global.css`: Design system and global styles.
- `js/products-data.js`: Centralized product data.
- `assets/`: Images and icons.
